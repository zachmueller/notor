# Notor Examples

Ready-to-use examples and templates for Notor. Browse the categories below, copy what you need into your vault, and customize.

## Categories

| Directory | Description |
|-----------|-------------|
| [extensions/](extensions/) | Community tool, automation, and chat block extensions |
| [workflows/](workflows/) | Reusable workflow templates |
| [orchestrations/](orchestrations/) | Multi-step orchestration patterns |
| [personas/](personas/) | Persona file examples |
| [rules/](rules/) | Rule file examples |

## Usage

Most examples are single `.md` files. Copy them into the corresponding directory in your vault's `notor/` folder, reload extensions or restart Obsidian, and you're set. Each file includes documentation explaining what it does and how to configure it.

See the [Extensions documentation](../docs/extensions.md) for the full file format specification and runtime APIs.
